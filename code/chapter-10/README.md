Chapter 10 code samples

Files:
- linked_list.c: singly linked list implementation (push, find, remove, free)
- stack.c: simple stack using linked nodes
- queue.c: queue implemented with head/tail pointers
- Makefile: build targets

Build:
- make

Run:
- ./linked_list
- ./stack
- ./queue

Notes:
- Examples demonstrate dynamic allocation and need for proper freeing to avoid leaks.
