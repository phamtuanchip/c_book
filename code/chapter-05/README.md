Chapter 5 code samples

Files:
- prime_check.c: simple prime checker using trial division and sqrt optimization
- multiplication_table.c: print multiplication table 1..N

Build:
- gcc -Wall -Wextra -std=c11 -o prime_check prime_check.c -lm
- gcc -Wall -Wextra -std=c11 -o multiplication_table multiplication_table.c

Run:
- ./prime_check
- ./multiplication_table
