KDP Upload Checklist

1. Files prepared:
   - manuscript (EPUB and source Markdown) -> formats/book.epub
   - sample chapter EPUB -> formats/sample_chapters.epub
   - cover image (JPEG, 300 DPI) -> kdp/cover.jpg or cover-placeholder.jpg
   - metadata (title, author, description) -> kdp/metadata.json and kdp/description.txt

2. Cover guidelines:
   - Recommended size for paperback: at least 300 DPI; height and width depend on page count.
   - For Kindle eBook cover: 2560 x 1600 pixels recommended (portrait), JPEG or TIFF.

3. KDP steps:
   - Sign in to kdp.amazon.com
   - Create new Kindle eBook, fill title/author/description
   - Upload manuscript EPUB
   - Upload cover (or use KDP cover creator)
   - Preview using online previewer and Kindle Previewer app
   - Set rights, pricing, territories
   - Publish

4. Optional: Use Kindle Create to produce KPF from EPUB for more consistent formatting.

5. QA:
   - Check TOC, images, code formatting, footnotes, and links
   - Validate EPUB using Kindle Previewer

6. Release:
   - Prepare sample pages, select pricing and distribution options
