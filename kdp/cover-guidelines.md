Cover guidelines for KDP

Ebook cover (Kindle):
- Recommended dimensions: 2560 x 1600 pixels (height x width) for best results.
- Minimum recommended height: 1000 pixels.
- Aspect ratio: Height/Width ≈ 1.6
- Format: JPEG or TIFF, RGB color profile.
- File size: under 50 MB.

Paperback cover (KDP Print):
- Requires full cover (front + back + spine) as a single PDF or image.
- Calculate spine width = page_count * paper_thickness (e.g., 0.0025 inches per page for cream paper) and include bleed.
- Use 300 DPI for print assets.

Design tips:
- Clear title and author name, legible at thumbnail size.
- Avoid small text for subtitle or series info.
- Provide high-contrast text over background.

Tools:
- GIMP, Photoshop, Affinity Designer for cover design.
- KDP Cover Creator can create basic covers from templates.
