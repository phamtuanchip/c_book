# Learn C Programming From Basics to Advanced: A Free Vietnamese Book in 22 Chapters

*From your first program to pointers, memory safety, threads, sockets, and two complete mini projects.*

C is still the language underneath operating systems, embedded devices and databases, and it is one of the best ways to really understand how computers work. This Vietnamese-language book takes you from a first program to systems-level topics. **An English edition is planned.**

## Who it is for

- Beginners who have never programmed
- CS and electronics students who want to go deep on C
- Developers refreshing their fundamentals or moving toward systems programming

## What is inside

22 chapters, roughly in four stages:

- **Getting started (ch. 1–4):** your first C program, programming concepts, the history and philosophy of C, syntax and program structure
- **Core language (ch. 5–10):** control flow, functions and scope, arrays and strings, a deep dive into pointers, memory management and common bugs, struct/union/enum
- **Building real programs (ch. 11–16):** headers, Makefiles and build systems, file I/O, error handling, the preprocessor and macros, POSIX threads and synchronisation, network programming with sockets
- **Professional practice (ch. 17–22):** optimisation and profiling, security and memory safety, two projects (a mini interpreter and a simple web server), testing and CI for C, packaging and deployment

Example code for each chapter lives in the repository with Makefiles, and exercise solutions are included.
